# TaskbarQuota-zh-CN

## 说明

本项目是原仓库 [zioder/TaskbarQuota](https://github.com/zioder/TaskbarQuota) 的简体中文 Fork。它不是只替换界面文字的汉化包：在保留原仓库多服务额度监控能力的基础上，本分支还包含功能调整、安装身份隔离，以及针对部分上游行为和缺陷的修正。

本文只记录本 Fork 相对于原项目的主要变化；原项目的通用功能、安装和构建说明不在此重复展开。

## 汉化范围

- 完成主窗口、仪表板、设置页、成本页、浮动窗口和快速面板的简体中文本地化；
- 覆盖服务名称、额度窗口、重置时间、动态状态、托盘菜单、通知、智能体活动和登录/凭据提示等运行时文案；
- 统一百分比、Token、更新时间、重置倒计时、数据来源和不可用状态的中文显示，避免界面已汉化但动态内容仍显示英文。

## 功能调整

- 使用独立的中文应用名称、AppId 和默认安装目录 `TaskbarQuota-zh-CN`，避免与英文版互相覆盖；同时提供 x64 自包含安装包和便携包，便携包不包含用户凭据文件；
- 将服务发现结果接入“隐藏不可用服务”策略：新用户默认显示全部服务，只自动隐藏最近一次明确报告为“尚未安装”的服务；登录失败、凭据失效或网络暂时不可用的服务不会被误判为未安装；关闭该选项后，被策略隐藏的服务可以恢复；
- 让供应商导航、仪表板开关、可用服务卡片和托盘入口保持同步，避免点击无效服务时回退到 Codex 或意外重新启用服务；
- 任务栏空间不足或布局重新测量时，只在内存中暂时隐藏放不下的非活动小组件，不改写用户的固定设置；
- 修正托盘上下文菜单的线程和异常处理路径，修正托盘图标创建时机导致的空白图标，并增加 EXE 图标回退路径；
- 卸载程序提供单一的“保留配置”选项：默认保留用户配置，取消后才清理当前及旧版配置目录；静默卸载路径也会安全保留配置。

## Codex 额度显示边界（本 Fork 修改）

本 Fork 针对 Codex 的额度读取和显示做了明确的实时性边界：

- 只有从 OpenAI 成功取得并确认的实时额度，才会作为当前 Codex 额度显示；
- 当网络中断、VPN 关闭、OpenAI 服务暂时无法访问、请求失败，或当前只有本地会话历史而没有可确认的实时额度时，任务栏和仪表板不会继续显示旧的订阅额度；
- 上述情况下保留 `5小时额度` 和 `每周额度` 标签，但数值显示为 `--`：

  ```text
  5小时额度 --
  每周额度 --
  ```

- `--` 表示“当前无法确认”，不表示额度为零；本地会话历史也不会被伪装成实时额度；
- 网络恢复并成功完成一次实时刷新后，才恢复显示新的 Codex 额度读数；
- 同时统一 Codex 额度标签和相关显示逻辑，避免把不适用于 Codex 的通用 credits 信息套用到 Codex 卡片。
