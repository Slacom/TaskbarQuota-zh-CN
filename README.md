# TaskbarQuota-zh-CN

## 说明

本项目是原仓库 [zioder/TaskbarQuota](https://github.com/zioder/TaskbarQuota) 的简体中文 Fork，当前同步到上游 **1.4.0**，Fork 发布版本为 **1.4.0.0**。

它保留上游的多服务额度监控和本地活动能力，并继续提供简体中文界面、独立安装身份以及本 Fork 原有的离线额度安全边界。

## 汉化范围

- 主窗口、仪表板、成本页、设置页、浮动窗口和快速面板；
- 服务名称、额度窗口、重置时间、动态状态、托盘菜单、通知、智能体活动和登录/凭据提示；
- 配额消耗速度预测、活动卡片忽略操作、供应商显示顺序、图标颜色、浮窗透明度和点击穿透等 1.4.0 新增界面；
- 百分比、Token、更新时间、重置倒计时、数据来源和不可用状态的中文显示。

## 1.4.0.0 同步内容（上游 1.4.0）

- 额度消耗速度预测、匀速刻度和预计用完时间；
- 可持久化的任务栏供应商显示顺序、彩色供应商图标和活动状态点；
- 浮动窗口整体透明度与点击穿透；
- 智能体活动卡片忽略、状态持续时间和闲置自动隐藏；
- Codex Business 支出上限、Claude 重置额度和更完整的桌面端凭据检测；
- Cursor、Antigravity、Grok Build 成本历史与更新后的模型价格；
- 多显示器身份、任务栏路由、固定预算及小部件稳定性修正；
- 进程扫描、历史解析和空闲内存方面的性能优化。

本轮保留上游的供应商发现和可见性实现，不额外叠加旧版自定义的不可用供应商隐藏策略；Codex Credits 卡片本轮也不做自定义隐藏，按上游 1.4.0 行为显示。

## 安装身份

- 中文版使用独立应用名称、AppId 和默认安装目录 `TaskbarQuota-zh-CN`，可与英文版并存；
- 本次交付为 x64 自包含安装包；
- 卸载时默认保留用户配置，取消“保留配置”后才清理当前及旧版配置目录。

## Codex 额度实时性

本 Fork 仍保留以下边界：

- 只有从 OpenAI 成功取得并确认的实时额度，才会作为当前 Codex 额度显示；
- 网络不可用、请求失败或只有本地会话历史时，任务栏和仪表板不会把旧数据继续显示为当前额度；
- 上述情况下显示：

  ```text
  5小时额度 --
  每周额度 --
  ```

- `--` 表示“当前无法确认”，不表示额度为零；
- 成功完成一次实时刷新后恢复显示新读数。
