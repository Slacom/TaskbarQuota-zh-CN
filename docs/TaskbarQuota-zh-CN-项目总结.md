# TaskbarQuota-zh-CN 项目总结

- Fork 版本：`1.4.0.0`
- 上游基线：`v1.4.0`
- 发布分支：`release/1.4.0.0`

## 同步状态

本版本已合并上游 1.4.0 的额度预测、任务栏供应商顺序、彩色供应商图标、智能体活动改进、浮窗透明度与点击穿透、成本历史扩展、多显示器修正和性能优化，并完成对应简体中文文案同步。

## 保留的 Fork 行为

- Codex 实时额度不可确认时显示 `5小时额度 --`、`每周额度 --`，不把旧快照或本地历史伪装成实时额度；
- 独立中文应用名称、AppId 和安装目录 `TaskbarQuota-zh-CN`；
- 保留配置的卸载流程；
- 重置/过期时间显示模式、中文字体与小组件布局定制。

## 本轮未叠加的旧定制

- 不额外移植旧版自定义的不可用供应商隐藏策略；使用上游 1.4.0 自带的发现与可见性逻辑；
- 不对 Codex Credits 卡片应用旧版自定义隐藏规则；使用上游 1.4.0 的显示逻辑。

## 已清理的遗留实现

- 删除未被生产路径调用、仅测试使用的 `ComputeNavigationProviderIds`；
- 删除已被非破坏式固定预算替代的 PinBudget hysteresis 与签名计算；
- 删除已被 1.4.0 显式列布局替代的旧列偏移辅助方法。

## 发布产物

安装器通过 `installer/TaskbarQuota.iss` 生成，默认输出到 `artifacts/`。GitHub fork 使用 `release/1.4.0.0` 分支与对应版本标签。
